## Overview

**Loader Portal** is a Java Swing desktop application designed as an Internal QA Automation Tool. It provides a user-friendly interface for uploading test files and managing automated testing processes.

### Key Features
- File upload functionality with visual feedback
- Process execution controls (Run, Reset, Track, Check Status)
- Real-time message display for process status
- Modern, clean user interface design
- Responsive layout with scroll support

### Technologies Used
- **Java Swing** - GUI framework
- **AWT** - Abstract Window Toolkit for event handling
- **BorderLayout, BoxLayout, FlowLayout, GridBagLayout** - Layout managers

---

## Application Architecture

The application follows a single-class design pattern with clear separation of concerns:

```
LoaderPortal (JFrame)
├── Instance Variables (UI Components & State)

├── initComponents() (UI Setup)
├── createButton() (Button Factory Method)
├── Event Handlers (selectFile, runProcess, etc.)
└── main() (Application Entry Point)
```

### 3. Button Factory Method - `createButton()`

**Purpose:** Creates consistently styled buttons with hover effects.

```java
private JButton createButton(String text, Color bgColor) {
    JButton btn = new JButton(text);
    btn.setBackground(bgColor);
    btn.setForeground(Color.WHITE);
    btn.setFont(new Font("Arial", Font.BOLD, 11));
    btn.setFocusPainted(false);
    btn.setBorderPainted(false);
    btn.setPreferredSize(new Dimension(145, 42));
    btn.setCursor(new Cursor(Cursor.HAND_CURSOR));
    
    // Hover effect
    btn.addMouseListener(new MouseAdapter() {
        public void mouseEntered(MouseEvent e) {
            btn.setBackground(bgColor.darker());
        }
        public void mouseExited(MouseEvent e) {
            btn.setBackground(bgColor);
        }
    });
    
    return btn;
}
```

**Features:**
- **Consistent Sizing:** All buttons are 145x42 pixels
- **Visual Feedback:** Background darkens on mouse hover
- **Professional Styling:** No focus border or button border
- **User Experience:** Hand cursor indicates clickability

**How it Works:**
1. Creates a new JButton with specified text
2. Applies color scheme and styling
3. Adds MouseListener for hover effects
4. Returns the configured button

### 4. File Selection - `selectFile()`

**Purpose:** Opens a file chooser dialog for user to select test files.

```java
private void selectFile() {
    JFileChooser fileChooser = new JFileChooser();
    int result = fileChooser.showOpenDialog(this);
    
    if (result == JFileChooser.APPROVE_OPTION) {
        selectedFile = fileChooser.getSelectedFile();
        statusLabel.setText("Selected: " + selectedFile.getName());
        statusLabel.setForeground(new Color(92, 184, 92));
        messageArea.setText("MESSAGE: File selected - " + selectedFile.getName() + 
            "\nReady to run process.");
    }
}
```

**Workflow:**
1. Creates a new `JFileChooser` instance
2. Opens system file dialog
3. If user selects a file:
   - Stores file reference in `selectedFile`
   - Updates status label with filename
   - Changes status text to green
   - Updates message area with confirmation

**User Feedback:**
- Visual confirmation via status label
- Color change to green indicates success
- Message area confirms selection

### 5. Process Execution - `runProcess()`

**Purpose:** Initiates the automation process with the selected file.

```java
private void runProcess() {
    if (selectedFile == null) {
        JOptionPane.showMessageDialog(this, "Please select a file first!", 
            "No File Selected", JOptionPane.WARNING_MESSAGE);
        return;
    }
    
    messageArea.setText("MESSAGE: Running process with file - " + selectedFile.getName() + 
        "\nProcessing...\nPlease wait...");
    
    // Simulate processing
    Timer timer = new Timer(2000, e -> {
        messageArea.append("\n\nProcess completed successfully!");
    });
    timer.setRepeats(false);
    timer.start();
}
```

**Workflow:**
1. **Validation:** Checks if a file has been selected
2. **Error Handling:** Shows warning dialog if no file selected
3. **Status Update:** Displays processing message
4. **Simulation:** Uses Timer to simulate 2-second process
5. **Completion:** Appends success message after delay

**Key Components:**
- **JOptionPane:** Modal dialog for error messages
- **Timer:** Simulates asynchronous processing (2000ms delay)
- **Non-repeating Timer:** Executes callback only once

**Real-World Implementation:**
Replace the Timer simulation with actual file processing logic:
```java
// Example: Replace timer with actual processing
new Thread(() -> {
    try {
        // Your file processing logic here
        processTestFile(selectedFile);
        SwingUtilities.invokeLater(() -> {
            messageArea.append("\n\nProcess completed successfully!");
        });
    } catch (Exception ex) {
        SwingUtilities.invokeLater(() -> {
            messageArea.append("\n\nError: " + ex.getMessage());
        });
    }
}).start();
```

### 9. Application Entry Point - `main()`

**Purpose:** Launches the application with proper Swing threading.

```java
public static void main(String[] args) {
    SwingUtilities.invokeLater(() -> {
        try {
            UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());
        } catch (Exception e) {
            e.printStackTrace();
        }
        
        LoaderPortal portal = new LoaderPortal();
        portal.setVisible(true);
    });
}
```

**Key Concepts:**

**SwingUtilities.invokeLater():**
- Ensures UI creation happens on the Event Dispatch Thread (EDT)
- Prevents threading issues in Swing applications
- Lambda expression creates a Runnable

**Look and Feel:**
```java
UIManager.setLookAndFeel(UIManager.getSystemLookAndFeelClassName());
```
- Sets application appearance to match the operating system
- Windows: Windows Look and Feel
- macOS: Aqua Look and Feel
- Linux: GTK+ Look and Feel

**Why This Matters:**
- Provides native appearance
- Better user experience
- Platform-specific behaviors

## Event Handling

### Event Flow Diagram

```
User Action → Event → Handler → UI Update
```

### Event Handlers Summary

| Button | Event Type | Handler Method | Action |
|--------|-----------|----------------|--------|
| Select File | ActionEvent | selectFile() | Opens file chooser |
| RUN | ActionEvent | runProcess() | Starts automation |
| RESET | ActionEvent | resetForm() | Clears form |
| TRACK | ActionEvent | trackProcess() | Shows tracking info |
| CHECK STATUS | ActionEvent | checkStatus() | Displays status |
| All Buttons | MouseEvent | (hover effect) | Color change |

### Event Handling Pattern

All buttons use ActionListener for clicks:
```java
buttonName.addActionListener(e -> methodName());
```

This is a lambda expression equivalent to:
```java
buttonName.addActionListener(new ActionListener() {
    public void actionPerformed(ActionEvent e) {
        methodName();
    }
});
```

## How to Run

### Prerequisites
- **Java JDK:** Version 8 or higher
- **IDE:** IntelliJ IDEA (recommended) or any Java IDE
- **Operating System:** Windows, macOS, or Linux

### Running in IntelliJ IDEA

**Step 1: Create Project**
1. Open IntelliJ IDEA
2. Create new Java project
3. Set JDK version

**Step 2: Add Source File**
1. Create new Java class named `LoaderPortal`
2. Copy and paste the code
3. Ensure package declaration matches project structure

**Step 3: Run Application**
1. Right-click on the file
2. Select "Run 'LoaderPortal.main()'"
3. Or click the green play button in the editor

**Step 4: Build Executable (Optional)**
1. Go to File → Project Structure → Artifacts
2. Add new JAR artifact
3. Build → Build Artifacts
4. Find JAR in `out/artifacts/` folder

### Running from Command Line

**Compile:**
```bash
javac LoaderPortal.java
```

**Run:**
```bash
java LoaderPortal
```

### Creating Executable JAR

**With Manifest:**
```bash

# Create JAR
jar cvfm LoaderPortal.jar manifest.txt LoaderPortal.class
```

## Troubleshooting

### Common Issues

**Issue 1: Icons Not Displaying**
- **Solution:** Use Unicode escape sequences (`\u2601`) instead of direct characters

**Issue 2: Layout Not Visible**
- **Solution:** Increase window size, check preferred/maximum sizes

**Issue 3: Buttons Not Aligned**
- **Solution:** Use appropriate layout manager (FlowLayout with CENTER)

**Issue 4: Application Doesn't Start**
- **Solution:** Ensure main method uses `SwingUtilities.invokeLater()`

**Issue 5: File Chooser Doesn't Open**
- **Solution:** Check file system permissions and paths
